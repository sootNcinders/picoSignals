# PicoSignals Configuration Editor

A multi-platform GUI application for creating, loading, and editing JSON configuration files for PicoSignals devices.

## Features

- **Multi-platform**: Works on Windows, macOS, and Linux
- **Intuitive GUI**: Tabbed interface for different configuration sections
- **File Operations**: Load and save JSON configuration files
- **Form Controls**:
  - Numerical parameters use spin boxes with up/down arrows
  - Non-numerical parameters use drop-down combo boxes
  - Checkboxes for boolean values

## Installation

The application requires Python 3 and PyQt6. PyQt6 has been installed in your environment.

## Usage

Run the application with:

```bash
python3 config_editor.py
```

Or make it executable and run directly:

```bash
./config_editor.py
```

## Interface

### General Tab
Configure basic settings like address, timing, battery thresholds, etc.

### Heads Tab
Configure signal heads with their destinations, dimming, and color settings.
- Select the head mode: **Discrete (GAR)** for traditional green/amber/red/lunar signals, or **RGB** for full color control
- **Discrete mode**: Shows green, amber, red, and lunar colors with pin, current, and brightness settings
- **RGB mode**: Different fields for each color:
  - **Green/Red**: Pin, current, and RGB values
  - **Blue**: Pin and current only (not displayable as a color)
  - **Amber/Lunar**: RGB values only (generated by mixing red/green/blue)

### Pins Tab
Configure input/output pins with their modes (capture, release, turnout) and associated heads.
The table automatically populates with pins from loaded configurations.

### JSON Tab
View and edit the raw JSON directly, with the ability to update the GUI from JSON changes.

## File Menu

- **New**: Create a new configuration with default values
- **Open**: Load an existing JSON configuration file and display its parameters in the GUI
- **Save**: Save the current configuration
- **Save As**: Save the configuration with a new filename

## Building Configurations

Use the GUI to set all parameters, then save the JSON file. The application validates inputs and ensures proper JSON structure.
